Hướng Dẫn Chạy Drupal Admin CMS Từ A-Z
Hệ thống quản trị (Admin Dashboard) của dự án được xây dựng trên nền tảng Drupal 10 chạy qua Docker. Vì Backend (FastAPI) đã được đẩy lên production trên Railway, Drupal chỉ đóng vai trò là một "vỏ bọc" kết nối API ra ngoài.

Dưới đây là hướng dẫn chi tiết từng bước để bạn khởi chạy và cấu hình Admin CMS từ đầu:

Bước 1: Khởi động hệ thống (Docker)
Mở ứng dụng Docker Desktop trên máy tính của bạn và đảm bảo nó đang chạy.
Mở Terminal (Command Prompt / PowerShell) và trỏ vào thư mục gốc của dự án:
bash
cd D:\ai_trans_demo
Chạy lệnh sau để khởi động Drupal và Database:
bash
docker-compose up -d
Lệnh này sẽ chạy 2 container: drupal (chứa code PHP/Apache) và drupal_db (chứa database MariaDB).
Bước 2: Cài đặt Drupal (Nếu là lần chạy đầu tiên)
Nếu đây là lần đầu tiên bạn chạy (do database chưa có dữ liệu), Drupal sẽ yêu cầu bạn cài đặt.

Mở trình duyệt và truy cập: http://localhost:8080
Chọn ngôn ngữ English -> Nhấn Save and continue.
Chọn profile Standard -> Nhấn Save and continue.
Ở màn hình Database Configuration, hãy điền chính xác như sau:
Database type: MySQL, MariaDB, Percona Server, or equivalent
Database name: drupal
Database username: drupal
Database password: drupal
Nhấn mở mục Advanced Options:
Host: drupal_db (Bắt buộc phải là drupal_db, tuyệt đối không để localhost)
Port: 3306
Nhấn Save and continue. Đợi Drupal tự động cài đặt các module cốt lõi (sẽ mất khoảng 1-2 phút).
Ở màn hình Configure site, nhập các thông tin tùy ý (Tên site, Email, Username admin, Password admin, v.v.) và nhấn Save.
Bước 3: Bật Module AI Translator
Sau khi đăng nhập vào giao diện Admin của Drupal, bạn cần bật module custom mà chúng ta đã code:

Nhìn lên thanh menu đen trên cùng, bấm vào nút Extend (hoặc truy cập http://localhost:8080/admin/modules).
Cuộn xuống cuối trang hoặc dùng ô tìm kiếm gõ chữ AI Translator.
Tích chọn vào ô vuông cạnh chữ AI Translator Admin.
Kéo xuống dưới cùng và nhấn nút Install. (Drupal sẽ thông báo Module đã được bật thành công).
Bước 4: Cấu hình kết nối với Backend Railway
Bây giờ chúng ta cần nói cho Drupal biết Backend FastAPI đang nằm ở đâu.

Trên thanh menu, bấm vào Configuration.
Tìm đến mục AI Translator Configuration (hoặc truy cập thẳng http://localhost:8080/admin/config/ai-translator/settings).
Điền các thông tin kết nối production:
FastAPI Base URL: https://ai-translator-system-production.up.railway.app/api/v1
Admin API Key: hle25zepezevide
Nhấn Save configuration.
Bước 5: Trải nghiệm Dashboard
Bạn đã cài đặt xong! Giờ hãy trải nghiệm bảng điều khiển của Admin:

Mở thanh menu -> Configuration -> AI Translator Dashboard. (Hoặc truy cập nhanh http://localhost:8080/admin/config/ai-translator/dashboard).
Tại đây bạn sẽ thấy các tính năng:
Xem cấu hình hiện tại đang kết nối đi đâu.
Nút Check API Status để kiểm tra Backend trên Railway có đang sống không.
Nút Clear Redis Cache để dọn dẹp các cache dịch cũ bị sai lệch trên Upstash Redis.
TIP

Nếu sau này bạn có chỉnh sửa code PHP hoặc giao diện của Module, bạn chỉ cần vào Configuration -> Performance -> Nhấn nút Clear all caches là thay đổi sẽ cập nhật ngay lập tức.
